# Rota de Prospecção Comercial

Aplicação para encontrar empresas que possam ser visitadas pela equipe comercial. Pesquise por cidade, categoria, palavra-chave ou bairro; consulte resultados no mapa; abra rotas; e registre visitas e anotações no navegador.

O mapa e a busca geográfica usam serviços do Google Maps, incluindo Places e Geocoding. O produto ajuda na prospecção comercial de soluções como ERP; não é um módulo integrado a um ERP.

## Executar localmente

1. Instale as dependências com `npm install`.
2. Configure a chave do Google Maps conforme as variáveis usadas pelo projeto, incluindo `VITE_GOOGLE_MAPS_API_KEY`.
3. Inicie com `npm run dev`.

Consulte `package.json` para os demais comandos disponíveis.
